# PGPG

## Description

PGPG is a code repository for **procedural generation of tablature-annotated guitar audio data and for the proposed fine-grained evaluation metrics**. It is implemented entirely in Python. Its main purpose is to create audio datasets with annotations for modeling, analysis, or synthesis tasks.

This repository **does not include pre-generated datasets** or large music data files. The data are generated by running the project's modules.

## Repository Structure

The folder and file organization on the main branch (`main`) is as follows:

```
PGPG/
├── Chord_Dictionaries/
│   └── ...
├── Generators/
│   └── ...
├── Combined/                    (generated after running the main script)
├── SingleNotesPerformances/     (generated after running)
├── ChordEventsPerformances/     (generated after running)
├── ComplexEventsPerformances/   (generated after running)
├── config.py
├── main.py
├── tabalturize_data.py
├── requirements.txt
└── .gitignore
```

### Components

* **Chord_Dictionaries/**
  JSON files with chord distributions or dictionaries that guide the generation of chord events.

* **Generators/**
  Module with the classes and functions that implement the event generators: single notes, chord events, and complex structures.

* **main.py**
  Main script that orchestrates the generation of the combined dataset from the different generators.

* **config.py**
  Configuration file defining the global data-generation parameters.

* **tabalturize_data.py**
  Additional utility to transform or tabulate the generated datasets.

* **requirements.txt**
  List of Python dependencies required to run the project.

## Usage

### Requirements

1. Python 3 installed on your system.
2. Install the dependencies listed in `requirements.txt`:

```
pip install -r requirements.txt
```

### Data Generation

Data are generated by running the main script, `main.py`. It combines the different generators to produce audio files and structured annotations (`.wav` and `.jams`).

Basic workflow:

1. **Parameter configuration**
   Set values such as the total number of files to generate (`NUM_FILES`) and the proportion of each generator type at the top of `main.py`.

2. **Generator execution**
   Running `main.py` creates three classes of musical events:

   * **Single notes**
     Produced by the `SingleNotesGenerator` module.

   * **Chord events**
     Produced by `ChordEventsGenerator` using the chord dictionaries.

   * **Complex events**
     A combination of notes and chords according to a specific configuration.

3. **Dataset unification**
   After the individual audio files and annotations are synthesized, the script gathers them into the `Combined/` folder for later use.

### Example

From the project root, run:

```
python main.py
```

This produces:

* `Combined/audios/`: audio files.
* `Combined/jams/`: annotations.

You can change variables such as the output folder, number of events, proportions, and dictionary paths directly in `main.py` before running.

## Notes

* The project **does not include pre-generated datasets**, for reasons of size and reproducibility; the data must be generated locally.
* Using JSON for the chord dictionaries makes it possible to modify or extend the musical rules without changing the code.
